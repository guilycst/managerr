- Intended result and capability limits: read-only `ports.FilesystemReadPort` implementation with bounded direct-child pages, opaque continuation cursors, SHA-256 hashing, device/inode-plus-size/mtime identity on Unix, exact root-relative manifests, component-aware upstream mapping and three-valued capability evidence. Unix paths resolve each component through directory descriptors with `O_NOFOLLOW`; root targets, traversal, symlinks and special files are rejected. Non-Unix fallback performs static no-symlink checks and reports no-follow capability as unknown.
- Changes completed / remaining: completed observer construction from configured roots, `Enumerate`/`EnumeratePage`, `Stat`, `Hash`, `Capabilities`, mapping selection/translation, permission probes and focused tests. Round-three replaces unbounded directory snapshots and consuming probes with a fixed-buffer descriptor stream retained behind a capped, idle-expiring cursor store. Round-four adds single-use generation tokens, stale replay rejection, cancellation invalidation, cumulative observed counts including exact-multiple terminal pages, and consumer use of the coordinator-owned ports evidence parser. Round-five linearizes cancellation invalidation by marking a continuation while its state mutex is still held, and checks that marker immediately after every continuation acquires the mutex; queued same-token calls therefore return stale without reading or advancing the stream. Each page inspects at most its requested child budget, unsupported siblings produce path-scoped reason evidence, and cursor metadata retains one source ID, start time and prior-partial marker through final coverage. Filesystem mutations, recursive discovery grouping and storage persistence remain downstream lanes.
- Correction scope: the frozen `ports.Page` contract has no unsupported-child collection or reason field. This lane uses `domain.Coverage.ReasonCodes` as a compatibility bridge with the prefix `unsupported_child:` followed by compact JSON `{"relativePath":"...","reason":"..."}`; the consumer-visible `ports.ParseUnsupportedChildReasonCode` parser and `ports.UnsupportedChildEvidence` type are the boundary for F-02. The coordinator should preserve this bridge or make the smallest explicit contract extension before discovery consumes it; unsupported children are never silently discarded or represented as valid manifests. The continuation cursor is process-local: it retains an open descriptor-backed stream, caps active cursors at 256, expires idle cursors after 10 minutes, rejects each generation after one use with `ErrEnumerationStale` (which wraps `ErrEnumerationCursor`), and returns stale after restart or eviction. Cancellation after stream access marks the retained state invalid while holding its mutex, releases the mutex, then removes the state; a queued same-token continuation checks the marker before any stream access and returns stale. Cancellation requires a fresh scan. Cumulative valid-manifest count travels in cursor state and every page's coverage, including empty terminal pages for exact multiples. This bounded stream is the stable-cursor equivalent on platforms where directory cookies are not portable.
- Coordinator integration: `golang.org/x/sys v0.47.0` is now a direct root-module dependency because Unix descriptor-relative observation imports `golang.org/x/sys/unix`. No module files were changed in this lane.
