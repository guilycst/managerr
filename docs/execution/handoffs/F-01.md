- Changes completed / remaining: completed observer construction from configured roots, `Enumerate`/`EnumeratePage`, `Stat`, `Hash`, `Capabilities`, mapping selection/translation, permission probes and focused tests. Filesystem mutations, recursive discovery grouping and storage persistence remain downstream lanes.
- Correction scope: the frozen `ports.Page` contract has no unsupported-child collection or reason field. This lane uses `domain.Coverage.ReasonCodes` as a compatibility bridge with the prefix `unsupported_child:` followed by compact JSON `{"relativePath":"...","reason":"..."}`; the consumer-visible `ports.ParseUnsupportedChildReasonCode` parser and `ports.UnsupportedChildEvidence` type are the boundary for F-02. The coordinator should preserve this bridge or make the smallest explicit contract extension before discovery consumes it; unsupported children are never silently discarded or represented as valid manifests. The continuation cursor is process-local: it retains an open descriptor-backed stream, caps active cursors at 256, expires idle cursors after 10 minutes, rejects each generation after one use with `ErrEnumerationStale` (which wraps `ErrEnumerationCursor`), and returns stale after restart or eviction. Cancellation after stream access invalidates the cursor and requires a fresh scan. Cumulative valid-manifest count travels in cursor state and every page's coverage, including empty terminal pages for exact multiples. This bounded stream is the stable-cursor equivalent on platforms where directory cookies are not portable.
