  inventory adapter to `github.com/guilycst/mastarr/clients/nzbget`.
- The adapter constructor now delegates endpoint validation, Basic
  authentication, request IDs, JSON-RPC 1.1 envelope validation, bounded
  response reads, same-origin redirects, deadline handling and typed upstream
  transport errors to the standalone client. The root adapter still owns
  connection scope, local pagination/cursors, path mappings, descriptors and
  conversion into the frozen Mastarr inventory and capability ports.
- `Version` consumes the standalone normalized `VersionObservation`. Queue and
  history calls use the standalone client's exported `Invoke` boundary with
  the exact positional arguments `listgroups([0])` and `history([false])`,
  capturing only the result as private `json.RawMessage`. This deliberate
  adapter-local seam preserves the existing item-level malformed-parameter,
  alias-conflict and positional-correlation evidence: the standalone
  convenience `ListGroups`/`History` methods intentionally use strict typed
  decoding and would otherwise discard an entire array when one item is
  malformed. No standalone generated DTO or wire type appears in an exported
  root adapter type.
- Standalone `UpstreamError` values are translated into the shared
  `domain.UpstreamError` contract. Status/RPC classifications, retryability,
  sanitized operation/detail fields and context cancellation/deadline matching
  are retained; standalone error types and raw upstream details do not cross
  the adapter boundary.
- Existing queue/history behavior remains intact: NZBID/ID aliases are
  correlated conservatively, exact `drone` semantics and redaction are
  retained, FinalDir/DestDir mapping stays component-aware, queue/history
  merging and partial reasons remain adapter-owned, descriptor availability is
  separate from history, and no mutation method was added.
- Existing synthetic fixtures were sufficient; no fixture or root module file
  was changed. No credentials, private endpoints, live inventories, media
  payloads or mutating requests were used.

unchanged. Coordinator integration must add the public requirement
`github.com/guilycst/mastarr/clients/nzbget`

