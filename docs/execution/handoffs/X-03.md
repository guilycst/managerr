## Contract and work

- Linked specification sections: `docs/plans/implementation.md` X-03; `docs/specs/spec-001-media-reconciliation/connectors.md` Arr section; acceptance cases A-07, A-09, A-10, A-11 and A-16. The adapter preserves the connection-scoped identity, root-relative `domain.FileTarget`, partial coverage and read-before-write boundaries from those documents.
- Product implementation is committed at `f12fe75568b263c285fe673598e8b97f7333634c` (`feat(arr): add read-only inventory and preview adapter`).
- `Client` implements `ports.MediaManagerReadPort` and `ports.CapabilityPort` for Radarr and Sonarr. It reads paginated movies/series, associated movie files/episodes, provider lookup, root folders, quality profiles and history. Numeric upstream identities remain scoped with the configured connection ID; invalid scope, path mapping, cursor and response conditions return sanitized typed upstream errors.
- Catalog and history pages use authenticated opaque per-client cursors, fixed page sizes, page/record/file/response bounds, de-duplication and explicit partial coverage reasons. Exact component-aware path mappings produce root-relative targets; unmapped and ambiguous paths remain visible as unresolved evidence.
- Native manual-import resources are typed against the pinned v3 source shapes: Radarr candidates carry nested `movie` and Sonarr candidates carry nested `series` plus exact `episodes`; native `rejections` preserve type/reason evidence. Multi-episode files retain every returned episode ID. Subtitle extensions and native language evidence are checked against the requested explicit subtitle association, while requested forced/SDH flags remain in the returned exact selection. Absolute and anime numbering remain explicit in the typed episode reference rather than inferred from release names.
- `PreviewImport` calls only `GET /api/v3/manualimport`. Because the Arr controller treats `movieId`/`seriesId` without `downloadId` as a library-file query, the common frozen port uses a folder-only query and verifies the nested native association before accepting a file. Callers with client provenance can use `PreviewImportWithDownloadID`, which sends `folder`, `downloadId`, and the exact movie/series ID. This avoids previewing a destination file accidentally.
- `ReprocessPreview` calls only `POST /api/v3/manualimport` with the exact supported Radarr (`path`, `movieId`, `downloadId`) or Sonarr (`path`, `seriesId`, `episodeIds`, `downloadId`) DTO. It does not send an `importMode`, expose arbitrary command JSON, or call `/api/v3/command`; native execution remains outside this read adapter. Native import execution capability is reported as unknown pending CAP-ARR-NO-OVERWRITE/X-05.
- Synthetic fixtures cover multi-page Radarr catalog and history, missing and unmonitored titles, nested Sonarr multi-episode associations, unmapped files, provider lookup, options, native rejection and reprocessing payloads, subtitle language/forced/SDH preservation, cursor scope and path boundaries. No live service, credential, private coordinate or media payload was used.
