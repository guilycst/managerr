## Remaining finding

### R2a — P2: hook validates working OpenAPI bytes rather than staged contract

Location: `scripts/check-guardrails.sh:100`-`:118`, invoked by `run_fast`.
Contract: versioned pre-commit must fail a candidate contract with schema errors;
local checks must not silently skip a failure. Generation already uses the exact
staged tree, so contract validation must preserve the same candidate binding.

The new standalone Vacuum loop reads `$repo_dir/$contract` directly. The staged
snapshot generator compares generated bytes, but an unknown top-level OpenAPI
field can leave generated Go output unchanged. If only the staged contract has
that error, generation succeeds and Vacuum checks the valid working-tree copy.

Independent sequential reproduction in an exact-product archive:

1. Initialize a synthetic Git baseline containing the product archive.
2. Append `unexpectedTopLevelField: true` to `clients/seerr/openapi.yaml`, then
   stage that file. With invalid staged and working bytes, aggregate `--fast`
   correctly fails, exit 1.
3. Restore only the working file from baseline, keeping the staged invalid blob.
   Independently compare working bytes with baseline and extract the staged blob.
4. Run the actual versioned `.githooks/pre-commit` from that probe repository
   under `GOWORK=off GOPROXY=off GOSUMDB=off`: exit 0; staged generation and fast
   guardrails report success.
5. Run pinned Vacuum directly on the extracted staged blob with repository ruleset,
   `--remote=false --fail-severity=warn`: exit 1, one schema error, zero warnings.

This is a concrete candidate-validation bypass; it uses no credential, endpoint
or live media. The new checks still fail in clean CI after committing the invalid
contract, so it is not a CI acceptance bypass. It violates the local hook's
candidate gate and cannot be fixed by validating the working copy more strictly.

Required correction: validate all standalone OpenAPI documents and their validation
policy from the exact candidate snapshot, or fail explicitly whenever their staged
bytes differ from the working bytes before any working-tree validation. Apply the
candidate binding consistently to standalone contracts and add a staged-only
invalid-document regression. Preserve deterministic offline tools and fail-on-warning.
