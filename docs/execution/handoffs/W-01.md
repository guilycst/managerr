## Product result

Product commit:
`3c4067d4d2562fbe3740a252bfd14f411824ed77`
(`feat(reconciliation): add evidence aggregation and immutable plans`).

`internal/reconciliation` provides a read-only aggregation boundary. Media is
keyed by provider ID plus media kind, while every tracking observation remains
scoped to its configured connection. The output has one instance projection per
connection and four independent dimensions: registration, import, availability
and request. Missing or unknown observations remain unknown; absent is accepted
only when the domain coverage proof is complete and fresh. Contradictory values
or external identities are retained as blocking conflicts, and title
disagreements remain explicit display conflicts. `ConfirmedAbsent` and
`FilterConfirmedAbsent` implement the filtered untracked view without storing a
universal tracked boolean.

`internal/planning` provides typed desired predicates for file content, file
identity, hardlinks, Arr registration/import, service state, episode mappings
and subtitle associations. It validates exact root-relative paths, file
identities, strong digests, recursive child manifests, overlap, size/depth/
entry bounds and action-specific shapes. Import selections preserve exact movie
or episode IDs, multi-episode associations, subtitle pair IDs, language,
forced/SDH labels and explicit video pairing. Ambiguous or unresolved mappings
are rejected before a plan can be ready.

Plans bind a source identity/revision, relevant connection and path-mapping
revisions, capabilities, exact manifest, preconditions, semantic desired state,
approval kind and an exclusive expiry window. Plan digests are deterministic and
include authority-bearing inputs while omitting display-only impact/conflict
prose. `NewRevision` creates a new revision without changing the previous plan;
approval checks the exact plan ID, revision and digest. `CheckCurrent` reports
source/config/mapping/capability/manifest/desired/expiry conflicts before a
write. `Evaluate` reports per-predicate `already_satisfied`, `needs_action`,
`unknown` or `conflict`; equal size/name never proves content, and equal bytes
never prove a hardlink without equal file identity.

These packages do not import adapters, storage, SQL rows, upstream DTOs or
workflow code. They do not perform media-system writes. API persistence and
typed executor wiring remain downstream integration work.

All fixtures use deterministic UUIDs, configured-root-relative synthetic targets
and synthetic digests/identities. No credentials, private coordinates, live
inventories, descriptors or real media were used.

## Correction round one

Product commit:
`7a7ab9883b377ff2e3e7e8be6d399c40c2f633c9`
(`fix(planning): enforce evidence and binding invariants`).

The correction closes all five findings from the prior independent review:

- `Plan.Validate` derives the canonical blocking set from authority-bearing
  `Conflicts`, checks the derived `Status` and `BlockingIssues`, and keeps those
  derived fields outside the digest as display/lifecycle projections. Mutating
  them cannot make a blocking plan approvable while the original digest stays
  unchanged.
- Arr import and episode/subtitle path-bearing predicates are checked against a
  recursively flattened exact manifest. Missing sources, nonexistent subtitle
  video references, directory roots used as files and wrong file roles are
  rejected; explicitly enumerated directory children are accepted.
- Desired predicates derive every target connection and require its connection
  configuration revision in the plan binding. Arr imports require a selected
  path-mapping revision as well. Current-state checks retain subset behavior, so
  unrelated configuration bindings may be omitted without weakening the target
  fence.
- Absence evidence is aged against the aggregation/filter clock. Stale complete
  absence becomes unknown at aggregation time and is rejected by
  `ConfirmedAbsentAt`/`FilterConfirmedAbsentAt` later, while cloned raw evidence
  remains available for review. The legacy convenience methods use the current
  UTC clock.
- Registration booleans and episode/absolute numbers are copied by value in
  predicate constructors and all desired-state normalization paths, including
  new revisions.

Focused regressions cover the digest-preserving blocking bypass, import source
and subtitle video scope, recursive directory-child acceptance, target and
mapping fences, stale absence at aggregation and later filtering, and scalar
pointer independence across desired-state construction, plan build and
revision creation.
