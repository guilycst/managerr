## Work completed

- Added `api/openapi.yaml` as the v0.0.1 wire contract. It contains 42 paths and
  55 operations covering health, connection/configuration resources, scans and
  observations, plans and review decisions, durable action/workflow execution,
  trash, descriptors and audit events.
- Added reusable schemas for coverage and cursor pagination, source/revision
  metadata, problem+json errors, exact `rootId` plus `relativePath` file targets,
  typed action inputs, immutable plan revisions/digests, approval binding,
  cancellation, deadlines, retry state and workflow steps.
- Typed action inputs cover Arr registration/import, filesystem copy/hardlink/
  move/rename/trash/restore/delete, qBittorrent stop/remove, descriptor delete
  and Jellyfin refresh. Seerr remains read-only. Jellyfin refresh has no
  availability implication.
- All mutating POST/PATCH/DELETE operations declare `Idempotency-Key` where a
  request creates work and configuration writes require `If-Match`. Created
  resources expose `Location` and revisions expose `ETag` where applicable.
- No OpenAPI security scheme or required Authorization header exists in v0.0.1.
  Response actor is the enum value `unauthenticated`; caller labels are
  explicitly unverified.
- Updated the HTTP reference to point at the authoritative OpenAPI file.
- Added strict oapi-codegen configurations for the root std-http server and UI
  client. Code generation and Go modules remain C-02 work.
