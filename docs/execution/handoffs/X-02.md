## Contract and work

- The adapter implements the frozen read-only `ports.DownloadInventoryPort` and `ports.CapabilityPort` contracts. It also exposes `ListDetailed`, `Version`, `ConnectionID` and `ScopedIdentity` for NZBGet-specific evidence without widening the common port.
- JSON-RPC requests use positional parameters from the supported NZBGet boundary: `listgroups([0])`, `history([false])` and `version([])`. Responses require JSON-RPC 2.0, a matching request ID and a bounded body. Basic credentials are applied per request; endpoint redirects remain same-origin and errors never include credentials, URLs or response bodies.
- Queue, post-processing and retained history evidence are preserved as separate typed observations. Recognized queue states map to queued, paused, downloading, processing or completed; only `PP_FINISHED` sets `ProcessingDone`. Unknown/future states, malformed parameters, invalid progress and incomplete processing remain visible with partial coverage reasons.
- NZBID is the canonical client identity. The deprecated `ID` alias is retained as evidence and never becomes a second item. When NZBID is absent, the alias is used as a conservative fallback; a disagreement between both positive IDs makes lifecycle state unknown and cannot prove completion. Arr correlation uses the `drone` parameter when present, otherwise canonical NZBID/alias fallback.
- Full-array queue/history responses are bounded by configured response bytes and item count. The merged view is locally paged with an instance-authenticated opaque cursor carrying source/start time, page count, offset, observed count, page size, prior-partial marker and snapshot digest. A changed full-array digest terminates continuation with partial coverage, preventing a mutable upstream snapshot from being claimed complete. Exact terminal pages retain cumulative `ObservedCount`.
- `FinalDir` is preferred over `DestDir`; mappings are component-aware and produce root-relative `domain.FileTarget` values. Missing or ambiguous mappings keep the observation visible while withholding a target and marking coverage partial. Source and destination mapping validation rejects relative or traversal paths.
- NZBGet history does not provide an exact filesystem manifest. `DownloadItem.Payload` therefore remains empty; filesystem observation must establish exact files before any action. Optional descriptor mode reads only a configured retained `.nzb` directory, uses `Lstat` and bounded reads, validates an XML `nzb` root, and returns metadata/digest only. Missing, malformed, unconfigured and disabled descriptor states stay distinct; descriptor bytes never enter ordinary inventory results.
- Categories and upstream parameters are provenance hints. The package contains no queue, history, post-processing, file or descriptor mutation methods.
