## Contract and work

- The adapter implements the frozen read-only `ports.DownloadInventoryPort` and `ports.CapabilityPort` contracts. It also exposes `ListDetailed`, `Version`, `ConnectionID` and `ScopedIdentity` for callers that need qBittorrent-specific evidence without widening the common port.
- Session handling uses `/api/v2/auth/login`, a private cookie jar, context-bound requests, bounded response reads, same-origin redirect enforcement and sanitized typed `domain.UpstreamError` values. Credentials, URLs and upstream bodies are never copied into errors or observations.
- Inventory reads qBittorrent WebUI version/application version, torrent summaries, properties, file metadata and optional descriptor export. It preserves state, progress, completion/addition timestamps, seeding, ratio, seed/leech counts, category/tags hints, content/save paths and v1/v2 hash values. Item identity is scoped as `connection-id:external-hash`; the common `ExternalID` remains the upstream hash.
- Pagination uses an opaque base64 cursor with a source ID, start time, offset, cumulative observed count, previous identities and page fingerprint. Limits apply to page size, page count, item count, response bytes, file count and optional descriptor bytes. Repeated/overlapping pages, response overflow, offset overflow and upstream caps terminate safely as partial coverage rather than looping or claiming absence.
- File observations preserve qBittorrent index/name/path/size/progress/priority/availability/seeds/is-seed. `availability=-1` and `seeds=-1` remain visible as unknown sentinels with partial reason evidence. Configured component-aware mappings produce root-relative `FileManifestEntry` values; unmapped or ambiguous files stay visible in detailed observations and cannot silently select a destination.
- Descriptor export is disabled by default. Best-effort mode returns only availability, size, SHA-256 digest, capture time and source after bounded bencode validation; descriptor bytes are never returned in an ordinary inventory page. A magnet-only or metadata-missing item reports a distinct unavailable state.
- Categories and tags are read-only provenance hints. No qBittorrent mutation, recategorization, deletion, torrent stop, file move or rename is present in this package.
