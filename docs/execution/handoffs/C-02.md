## Work completed

- Added independent modules:
  - root: `github.com/guilycst/managerr`
  - UI: `github.com/guilycst/managerr/ui`
  - tools: `github.com/guilycst/managerr/tools`
- Pinned Go `1.27.0` language semantics with `go1.27.1` toolchain selection in
  all three modules.
- Pinned runtime compatibility dependencies to
  `github.com/golang-migrate/migrate/v4 v4.19.1`,
  `modernc.org/sqlite v1.56.0` and
  `github.com/oapi-codegen/runtime v1.7.0`.
- Pinned the development tools module to oapi-codegen v2.8.0, sqlc v1.31.1,
  migrate v4.19.1 and envdoc v1.11.0 through Go `tool` directives. The tools
  module also carries a pure-Go SQLite/migrate compatibility test.
- Added `scripts/generate.sh`. `--check` generates both oapi-codegen outputs in
  a disposable directory and compares existing tracked outputs; `--write` writes
  them to the configured paths. It uses the tools module with `GOWORK=off` and
  invokes sqlc only after `sqlc.yaml` exists.
- Added GitHub Actions checks for root, UI and tools modules. Each module runs
  download, verify, test and vet with `GOWORK=off`; empty root/UI modules are
  accepted until their first packages land. A separate job checks generation and
  a clean diff.
- Added no `go.work`, local `replace`, application code, generated consumers,
  credentials or live-stack fixtures.
