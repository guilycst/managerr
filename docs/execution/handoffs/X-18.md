## Contract and work

- Linked specification sections and relevant invariants: X-18 in
  `docs/plans/implementation.md`; the Seerr connector section in
  `docs/specs/spec-001-media-reconciliation/connectors.md`; A-08, A-09, A-45
  and A-54 in `docs/verification/acceptance.md`. The client preserves native
  status and independent availability evidence, treats missing evidence as
  unknown, and has no Seerr writes in v0.0.1.
- Intended result and capability limits: an independent nested Go module with
  a Mastarr-owned OpenAPI 3.1.1 compatibility contract for `/api/v1/status`,
  `/api/v1/media` and `/api/v1/request`. The read surface preserves provider
  IDs, service relationships, native media/request status, 4K status, nested
  requests/seasons, Jellyfin identifiers, timestamps and typed service errors.
  It does not create, approve, cancel or delete requests, search, call hidden
  discovery APIs, or expose generated upstream DTOs.
- Changes completed / remaining:
  - Added API-key (`X-Api-Key`) and bearer authentication with aliases,
    endpoint/path validation, per-request deadlines, redirect refusal,
    response bounds and sanitized typed errors.
  - Added strict pre-decode checks for invalid UTF-8, duplicate object keys,
    trailing JSON and excessive nesting. Unknown upstream members remain
    forward-compatible at the generated boundary and are not copied into
    normalized public observations.
  - Added authenticated client-local continuation cursors with collection,
    page, count and seen-identity state. Native pageInfo is presence-aware;
    missing/incomplete/contradictory or changing metadata, duplicate pages,
    short pages, record/page limits and mutable offset traversal retain
    partial or unknown coverage and never claim a complete immutable snapshot.
  - Added `ListMedia`, `ListRequests`, `ListAllMedia` and
    `ListAllRequests`, plus status/version aliases and normalized native enum
    names. Seerr request writes are intentionally deferred to a reviewed
    extension.
